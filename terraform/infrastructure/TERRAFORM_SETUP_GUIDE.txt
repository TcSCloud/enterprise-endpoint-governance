## 🔑 STEP 3: Get Your Azure Subscription ID (2 mins)

You need your Azure Subscription ID. Get it via:

**Option A: Azure Portal**
1. Go to: https://portal.azure.com
2. Search for "Subscriptions"
3. Copy your Subscription ID

**Option B: PowerShell**
```powershell
# Install Azure PowerShell if needed
Install-Module -Name Az -AllowClobber -Force

# Login
Connect-AzAccount

# Get Subscription ID
Get-AzSubscription
# Copy the "Id" field
```

**Option C: Azure CLI**
```bash
# Login
az login

# List subscriptions
az account list --output table
# Copy the "SubscriptionId"
```

## 📝 STEP 4: Create terraform.tfvars File (3 mins)

```powershell
cd D:\CloudProject\IntunePack\Taiwot.com\Dev\enterprise-endpoint-governance\terraform\infrastructure

# Copy the example file
cp terraform.tfvars.example terraform.tfvars

# Edit terraform.tfvars with your REAL values
notepad terraform.tfvars
```

**Fill in with YOUR values:**

```hcl
environment     = "dev"
location        = "UK South"
subscription_id = "YOUR_AZURE_SUBSCRIPTION_ID_HERE"
client_id       = "bdedbf78-8602-4c71-92b6-6a00b7c5006a"
client_secret   = "YOUR_CURRENT_CLIENT_SECRET_HERE"
tenant_id       = "4764c71a-d508-4dd2-8a72-38fd70bad969"
```

**⚠️ IMPORTANT:** 
- Replace `YOUR_AZURE_SUBSCRIPTION_ID_HERE` with your actual subscription ID
- Replace `YOUR_CURRENT_CLIENT_SECRET_HERE` with your current Azure service principal secret
- The client_id and tenant_id above are YOUR existing ones

**Save and close the file.**

## 🆘 TROUBLESHOOTING:

### Error: "Subscription not found"
- Check your subscription_id in terraform.tfvars
- Verify you're logged into the correct Azure account

### Error: "Authorization failed"
- Check your client_secret is current and valid
- Verify service principal has Contributor role on subscription

### Error: "Storage account name already exists"
- This is OK - the random suffix ensures uniqueness
- If it fails, run `terraform apply` again

### Error: "terraform: command not found"
- Restart PowerShell after installing Terraform
- Verify installation: `terraform version`
